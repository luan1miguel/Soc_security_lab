OVERVIEW 

This project simulates a real-world cybersecurity environment focused on both offensive and defensive security practices.
The lab was built using Wazuh (SIEM), OPNsense (Firewall), ModSecurity (WAF), Kali Linux, and vulnerable Linux/Windows machines to practice attack simulation, threat detection, log analysis, rule creation, firewall hardening, web application protection,defense evasion and controlled exploitation of vulnerabilities and CVEs.

The main goal of this project is to improve hands-on skills in:
- Detection Engineering
- Security Monitoring
- Threat Hunting
- Incident Response
- Offensive Security
- Network Defense
- SIEM Rule Development
- Web Application Security
- Attack Detection & Evasion Techniques

This repository documents attack scenarios, custom detection rules, firewall configurations, active response mechanisms, and mitigation techniques developed during the lab activities.
